# SMB Web & Data

A small senior studio for SMBs and ecommerce brands. We build the Shopify store, run the marketing, and wire the data into reporting you can actually use.

**Services:** Build (Shopify stores & websites) · Grow (campaigns, ads & lifecycle) · Measure (analytics, pipelines & reporting)

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js (React) |
| Styling | Tailwind CSS |
| Fonts | Inter, JetBrains Mono |
| Data | BigQuery, dbt, Airbyte, Looker |
| Platforms | Shopify, Meta Ads, Google Ads |

## Development

```bash
# preview locally
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

## Deployment

Push to `main` to deploy via your hosting provider (Netlify, Vercel, Cloudflare Pages, etc.). The site is fully static — no build step required.
